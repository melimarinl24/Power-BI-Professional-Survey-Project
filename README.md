# Power BI Data Professional Survey Dashboard

Interactive Power BI dashboard analyzing survey responses from data professionals.

## Overview

This project focuses on cleaning, transforming, and visualizing survey data from data professionals using Power BI.

The goal was to create an interactive dashboard that makes it easier to explore trends related to salary, career satisfaction, demographics, and experiences entering the data field.

## Tools Used

- Power BI
- Power Query
- Data Cleaning
- Data Visualization

## Dataset

The dataset contains survey responses from data professionals and includes information such as:

- Job title
- Salary
- Age
- Country
- Career satisfaction
- Salary satisfaction
- Difficulty entering the data field
- Preferred programming language
- Industry and professional background

## Project Process

During this project, I:

- Imported the survey dataset into Power BI
- Cleaned and transformed the data using Power Query
- Standardized and prepared fields for analysis
- Created calculated summaries and visualizations
- Built an interactive dashboard
- Added filters and slicers to make the dashboard easier to explore

## Dashboard Highlights

The dashboard explores areas such as:

- Total number of survey participants
- Average age of survey participants
- Salary trends
- Career and work-life satisfaction
- Difficulty entering the data field
- Demographic and professional patterns
